## 1. Persiapan Sebelum Upload

### 1.1 — Masuk ke Dashboard Admin

1. Buka website toko Anda (misal `https://berkatmandiripendingin.com`).
2. Klik menu **"Masuk Admin"** di kanan atas, **atau** langsung buka alamat:
   ```
   https://alamat-website.com/#/admin
   ```
3. Masukkan username dan password:
   | Kolom | Isi Default |
   |-------|-------------|
   | Username | `admin` |
   | Password | `admin123` |
4. Klik tombol **"Masuk"**. Anda akan dibawa ke halaman **Ringkasan** (dashboard).

> ⚠️ **WAJIB:** Segera ganti password default! Caranya: menu **Pengaturan** → kartu **"Ubah Password Admin"** → isi password lama & baru → klik **"Ubah Password"**. Password minimal 6 karakter.

### 1.2 — Siapkan "Ammunisi" Anda

Sebelum menyentuh form, siapkan 2 hal ini. **Yang sudah siap, upload-nya cuma 3 menit per barang.**

**📸 A. Foto Barang** (detail lengkap di [Bagian 4](#4-panduan-foto-produk-yang-membuat-pembeli-percaya))

- [ ] Foto barang **asli** milik toko Anda (bukan gambar internet milik orang lain)
- [ ] Latar polos (tembok putih / abu terang / meja rapi)
- [ ] Format **JPG, PNG, WEBP, atau GIF** — bukan HEIC (foto iPhone mentah)
- [ ] Ukuran **maksimal 3MB per foto**
- [ ] Siapkan **3–6 foto per barang**: tampak utama, label tipe/kode part, port/terminal, dan kelengkapan

**📝 B. Data Barang** (catat di buku / HP / spreadsheet)

| Data | Contoh |
|------|--------|
| Nama lengkap barang | Kompresor Rotary Daikin 1 PK |
| Kode part / tipe (jika ada) | JT125BAY1L |
| Merek | Daikin |
| Kategori | Kompresor AC Split & Cassette |

| Satuan | pcs |
| Spesifikasi teknis | Voltase 220V, Refrigeran R32, dll. |
| Keunggulan / catatan | Original, garansi 6 bulan |

### Arti Setiap Kolom

| Kolom | Wajib? | Aturan | Contoh Isi |
|-------|--------|--------|------------|
| **Nama Produk** | ✅ Wajib | Sejelas mungkin, sertakan tipe/kode part | `Kompresor Rotary Daikin 1 PK (JT125BAY1L)` |
| **Merek** | Opsional | Nama brand saja, tanpa kata "merek" | `Daikin` |
| **Kode / SKU** | Opsional | Kode internal toko Anda (bebas polanya) | `CMP-DKN-1PK` |
| **Kategori** | Opsional | Pilih dari dropdown; ada pilihan "Tanpa kategori" | `Kompresor AC Split & Cassette` |
| **Deskripsi Singkat** | Opsional | **Maks 160 karakter** (ada penghitung otomatis). Tampil di kartu produk katalog | `Kompresor rotary original Daikin untuk AC split 1 PK. Garansi 6 bulan.` |
| **Deskripsi Lengkap** | Opsional | Bebas panjang. Pisahkan paragraf dengan Enter. Tampil di halaman detail | *(lihat Bagian 5)* |
| **Spesifikasi Teknis** | Opsional | Klik **"Tambah Baris"** untuk tiap detail. Kolom kiri = nama, kanan = isi | `Voltase` → `220V / 50Hz` |
| **Harga (Rp)** | Opsional | Angka saja, **tanpa titik/koma/Rp**. Kosongkan → tampil *"Hubungi Kami"* | `1850000` |
| **Satuan** | Otomatis `pcs` | Pilih: `pcs, set, box, pack, kg, meter, liter` | `pcs` |
| **Stok** | Otomatis `0` | Angka. Stok `0` → label **"Stok Habis"** di katalog | `5` |
| **Foto Produk** | Sangat disarankan | JPG/PNG/WEBP/GIF, maks 3MB, boleh pilih banyak sekaligus. **Foto pertama = foto utama** | — |
| **Tampilkan di Katalog** | Default ON | OFF = barang disembunyikan dari pengunjung (belum dihapus) | ON |
| **Produk Unggulan** | Default OFF | ON = tampil di bagian **"Produk Unggulan"** di beranda | OFF |

> 🧠 **Ingat polanya:** hanya **Nama Produk** yang wajib. Semua kolom lain boleh dikosongkan — jadi kalau buru-buru, isi nama + harga + foto dulu, sisanya bisa diedit kapan saja.

## 3. Tutorial Inti: Upload Barang Baru (10 Langkah)

Ikuti satu per satu. Contoh kasus: **mengupload 1 buah Kompresor AC Daikin**.

### ▶️ Langkah 1 — Buka Form Tambah Produk

- Login admin → klik menu **"Produk"** di sidebar kiri.
- Klik tombol **"Tambah"** di kanan atas tabel.
- Form kosong terbuka dengan judul area isian **"Informasi Produk"**.

### ▶️ Langkah 2 — Isi Nama Produk

Klik kolom **"Nama Produk"**, tulis dengan formula jagoan ini:

```
[Jenis Barang] + [Merek] + [Kapasitas / Tipe] + ([Kode Part])
```

| ❌ Nama Kurang Baik | ✅ Nama Bagus |
|---|---|
| Kompresor | Kompresor Rotary Daikin 1 PK (JT125BAY1L) |
| Kapasitor 35uF | Kapasitor Running 35uF 450V AC — Universal |
| Freon | Freon R32 Original 1.8kg (Sapi) |
| Motor fan | Motor Fan Outdoor Panasonic 20W (WA9528AVY7031) |

> 🎯 **Kenapa harus detail?** Pelanggan mengetik "kompresor daikin 1pk" di kotak pencarian katalog. Nama yang lengkap = barang Anda ketemu = laku.

### ▶️ Langkah 3 — Isi Merek, SKU, dan Kategori

- **Merek**: tulis `Daikin` (huruf awal kapital, tanpa tanda kutip).
- **Kode / SKU**: buat kode internal agar mudah dilacak, pola bebas. Pola yang kami sarankan:
  ```
  [Kategori 3 huruf]-[Merek 3 huruf]-[Tipe]
  Contoh: CMP-DKN-1PK · KAP-UNI-35UF · FRN-SAP-R32
  ```
- **Kategori**: klik dropdown → pilih `Kompresor AC Split & Cassette`.
  (Kalau belum tahu daftarnya, lihat [tabel kategori di Bagian 1.3](#13--daftar-kategori-yang-tersedia).)

### ▶️ Langkah 4 — Tulis Deskripsi Singkat

Maksimal **160 karakter** (penghitung `x/160` berubah warna otomatis di kanan label).

Rumusnya: **apa barangnya + untuk apa + keunggulan utama**.

```
Kompresor rotary original Daikin untuk AC split 1 PK. Pendingin kencang,
hemat listrik, garansi resmi 6 bulan tukar unit.
```

Deskripsi inilah yang muncul di **kartu produk** saat pengunjung melihat katalog — jadi buat sekilas menggoda.

### ▶️ Langkah 5 — Tulis Deskripsi Lengkap

Klik kotak besar **"Deskripsi Lengkap"**. Tulis **4 paragraf** dipisah Enter:

1. **Paragraf 1 — Fungsi**: part ini untuk apa, dipakai di alat apa.
2. **Paragraf 2 — Kompatibilitas**: cocok untuk tipe/ukuran AC apa saja.
3. **Paragraf 3 — Keunggulan**: original/aftermarket, kondisi, keuntungan.
4. **Paragraf 4 — Garansi & Pengiriman**: garansi berapa lama, dikirim hari yang sama, dikemas aman.

> 📋 Malas menulis? **Salin template jadi di [Bagian 5](#5-menulis-deskripsi-yang-menjual)** — tinggal ganti beberapa kata.

### ▶️ Langkah 6 — Isi Spesifikasi Teknis

Di kartu **"Spesifikasi Teknis"**:

1. Klik tombol **"＋ Tambah Baris"** → muncul sepasang kolom kosong.
2. Kolom kiri = **nama spesifikasi** (mis: `Voltase`), kolom kanan = **isinya** (mis: `220V / 50Hz`).
3. Ulangi "Tambah Baris" untuk tiap detail (5–8 baris sudah bagus).
4. Salah ketik? Klik ikon **🗑️ merah** di ujung baris untuk menghapusnya.

Rekomendasi baris per kategori: lihat **[Bagian 6](#6-spesifikasi-teknis--contoh-per-kategori)**.

### ▶️ Langkah 7 — Isi Harga, Satuan, dan Stok

Di kartu **"Harga & Stok"** (kolom kanan):

- **Harga (Rp)**: tulis `1850000` — **tanpa titik, tanpa koma, tanpa "Rp"**. Sistem otomatis menampilkan `Rp 1.850.000`.
  → Barang borongan/harga berubah-ubah? **Kosongkan** — katalog akan menampilkan tombol *"Hubungi Kami"*.
- **Satuan**: biarkan `pcs` untuk barang satuan; `kg` untuk freon; `box` untuk isi lusinan; `meter` untuk pipa/kabel.
- **Stok**: tulis jumlah fisik di gudang, misal `5`. Kalau barangnya habis tapi masih mau dipajang, tulis `0` — kartu produk otomatis diberi label **"Stok Habis"**.

### ▶️ Langkah 8 — Upload Foto Barang

Di kartu **"Foto Produk"**:

1. Klik area **bergaris putus-putus** bertuliskan *"Klik untuk pilih foto dari perangkat"*.
2. Pilih **banyak foto sekaligus** (tahan `Ctrl` / `Cmd` saat klik, atau blok semua file). Proses unggah ditandai spinner *"Mengunggah N foto..."*.
3. Setelah selesai, foto muncul dalam grid 3 kolom. Foto paling depan diberi label **"Utama"** — inilah yang tampil besar di katalog.
4. Hapus foto yang salah: **arahkan kursor ke foto → klik ❌** di pojok kanan atasnya.
5. Ingin ganti foto utama? Hapus foto yang sekarang jadi utama → foto kedua otomatis naik jadi utama. Atau hapus semua lalu unggah ulang dengan urutan yang benar.

> 📏 Aturan foto: **JPG/PNG/WEBP/GIF · maks 3MB · rasio persegi (1:1) paling rapi**. Panduan lengkap + cara kompres: [Bagian 4](#4-panduan-foto-produk-yang-membuat-pembeli-percaya).

### ▶️ Langkah 9 — Atur Status Tampilan

Di kartu **"Status Tampilan"**:

| Switch | Posisi | Artinya |
|--------|--------|---------|
| **Tampilkan di Katalog** | ON (default) | Barang langsung terlihat pengunjung. OFF untuk menyimpan draft tanpa dipajang. |
| **Produk Unggulan** | OFF (default) | Geser ON hanya untuk **barang terlaris** (4–8 produk cukup) agar tampil di beranda. |

### ▶️ Langkah 10 — Simpan & Periksa

1. Klik tombol **"💾 Simpan Produk"** (kanan atas, atau tombol lebar di bawah kolom kanan saat dari HP).
2. Tunggu notifikasi hijau **"Produk baru berhasil ditambahkan!"** — Anda otomatis dibawa ke tabel daftar produk.
3. Cek hasilnya di katalog publik: buka beranda → menu **Katalog** → cari nama barang Anda.
4. Cek juga halaman detailnya: klik kartu produk → pastikan foto, deskripsi, spesifikasi, dan harga tampil benar.

🎉 **Selesai!** Waktu normal per barang setelah terbiasa: **2–4 menit**.

## 4. Panduan Foto Produk (yang Membuat Pembeli Percaya)

### 4.1 — Enam Aturan Emas Foto

| # | Aturan | Alasan |
|---|--------|--------|
| 1 | Foto barang **asli** milik toko | Foto ambil-an internet sering blur + ber-watermark toko lain → menurunkan kepercayaan |
| 2 | Latar **polos** (tembok putih/abu) | Barang jadi fokus, katalog terlihat premium & seragam |
| 3 | Cahaya dari **jendela siang hari**, tanpa flash | Warna barang tidak menipu |
| 4 | Rasio **1:1 (persegi)**, barang memenuhi ±80% frame | Kartu katalog persegi — foto landscape akan ter-crop kiri-kanan |
| 5 | **3–6 foto** per barang | Pembeli bisa mengecek label tipe, port, dan kondisi |
| 6 | Ukuran file **≤ 3MB**, format JPG/PNG/WEBP/GIF | Batas sistem upload |

### 4.2 — Cara Memotret dengan HP (5 Menit)

1. Taruh barang di depan tembok putih / kertas gambar A3 putih.
2. Mode foto normal (jangan bokeh/pro mode), matikan flash.
3. Jarak ±30–50 cm, ketuk layar di barang agar fokus, ambil:
   - Foto 1: tampak depan/serong **(untuk foto utama)**
   - Foto 2: **label nama tipe / kode part** (paling penting untuk sparepart!)
   - Foto 3: port, terminal, atau sambungan
   - Foto 4: barang keseluruhan + kelengkapan (bungkus, kabel, aksesoris)
4. Bersihkan latar yang berantakan dengan crop bawaan HP bila perlu.

### 4.3 — Foto > 3MB? Kompres Dulu (2 Cara)

**Cara A — Situs kompresi (paling gampang):**
1. Buka `tinypng.com` (atau `squoosh.app`, `iloveimg.com/resize-image`) dari HP/laptop.
2. Seret semua foto ke halaman → tunggu proses → klik **Download**.
3. Hasilnya biasanya turun ke 100–500KB per foto **tanpa terlihat bedanya**.

**Cara B — Langsung dari HP:**
- **Android**: buka foto di Galeri → Edit → simpan sebagai salinan (kualitas otomatis turun), atau gunakan aplikasi *Photo Compress*.
- **iPhone**: foto dikirim via WhatsApp "tanpa kompresi jangan" → ambil dari chat (otomatis terkompresi ke ~200KB), atau screenshot lalu crop.

### 4.4 — ⚠️ Khusus Pengguna iPhone: HEIC Tidak Diterima!

Foto iPhone modern tersimpan sebagai **HEIC** (`IMG_1234.HEIC`). Sistem upload hanya menerima JPG/PNG/WEBP/GIF, sehingga akan muncul pesan *"Format harus JPG, PNG, WEBP, atau GIF."*

**Solusi (pilih salah satu):**
- **Paling cepat**: kirim foto ke chat WhatsApp → simpan dari sana → otomatis menjadi JPG.
- **Permanen**: `Pengaturan → Kamera → Format` → pilih **"Most Compatible"** → foto berikutnya langsung JPG.
- **Banyak file sekaligus**: buka `heictojpg.com` atau konversi via situs kompresi di atas.

### 4.5 — Urutan Foto yang Benar

```
[Foto 1 · UTAMA]  Tampak serong 45°, barang utuh & menarik
[Foto 2]          Label tipe / kode part / plat nama (zoom jelas)
[Foto 3]          Detail penting: port, terminal, colokan, bekas pakai
[Foto 4]          Tampak atas/samping
[Foto 5]          Kelengkapan paket + kemasan
[Foto 6]          (Opsional) foto kedua barang dengan stok berbeda
```

## 5. Menulis Deskripsi yang Menjual

### 5.1 — Template Siap Salin (Deskripsi Lengkap)

Salin blok ini ke kolom "Deskripsi Lengkap", lalu ganti kata di `{kurung}`:

```
{Nama barang} original untuk {jenis alat, misal: AC split 1 PK / kulkas 1 pintu / AC mobil}.
Berfungsi untuk {fungsi utama part} dan cocok digunakan pada {daftar tipe}.

Spesifikasi lengkap dapat dilihat pada bagian spesifikasi di bawah. Barang
dikirim pada hari yang sama untuk order sebelum jam 15.00, dikemas dengan
bubble wrap + kayu pelapis agar aman di perjalanan.

Kondisi: {baru 100% / original / aftermarket berkualitas}. Semua unit
{dicek & ditest sebelum dikirim}. Stok fisik tersedia di toko — silakan
langsung order atau tanya-tanya dulu via WhatsApp.

Garansi {6 bulan / sesuai nota} {tukar unit / ganti baru} untuk kerusakan
pabrik. Harga sudah langsung dari toko, makin banyak makin murah!
```

### 5.2 — Template Deskripsi Singkat (≤160 Karakter)

```
{Nama barang} untuk {aplikasi}. {Keunggulan 1 frasa} — garansi {X} bulan, stok ready.
```

Contoh: `Kompresor rotary Daikin 1 PK untuk AC split. Original, test OK, dikirim hari yang sama — garansi 6 bulan, stok ready.`

### 5.3 — Contoh Jadi #1: Kompresor AC

> **Deskripsi Singkat:**
> `Kompresor rotary Panasonic original untuk AC split 1 PK (type 2PS164DAA02). Test OK, garansi 6 bulan — stok ready, dikirim hari yang sama.`

> **Deskripsi Lengkap:**
> Kompresor rotary Panasonic 1 PK original untuk AC split standing/standing inverter. Berfungsi sebagai "jantung" AC: memampatkan refrigeran agar sirkulasi pendinginan kembali kencang, solusi untuk AC kurang dingin, keluar angin saja, atau pipa kembal tidak panas.
>
> Kompatibel untuk AC split 1 PK merek Panasonic type 2PS164DAA02 dan tipe lain dengan spesifikasi senada (mohon cocokkan tipe kompresor lama Anda sebelum order, foto label kami bantu cek via WhatsApp).
>
> Kondisi baru 100%, original Panasonic. Setiap unit di-check derau & hisan sebelum dikirim. Tersedia juga tipe ¾ PK, 1,5 PK, dan 2 PK — silakan lihat katalog.
>
> Garansi tukar unit 6 bulan untuk kerusakan pabrik. Order sebelum jam 15.00 dikirim hari yang sama, dikemas bubble wrap tebal + kayu pelapis.

### 5.4 — Contoh Jadi #2: Kapasitor

> **Deskripsi Singkat:**
> `Kapasitor running 35uF 450V AC universal untuk motor fan & kompresor AC. Ukuran pas standar, cek OK — ready stok.`

### 5.5 — Contoh Jadi #3: Freon / Gas

> **Deskripsi Singkat:**
> `Freon R32 original 1.8kg untuk AC split inverter new R32. Segel resmi, ready stok — isi ulang & ganti freon jadi maknyus.`

### 5.6 — Kata yang Sebaiknya Dihindari

| ❌ Hindari | ✅ Ganti Dengan |
|-----------|----------------|
| "Terbaik di Indonesia!", "No. 1", "Termurah sedunia" | "Harga langsung dari toko", "Makin banyak makin murah" |
| "100% pasti awet selamanya" | "Garansi 6 bulan tukar unit" |
| "Bisa untuk semua AC" | "Cocok untuk tipe ... (bantu cek via WhatsApp)" |

## 6. Spesifikasi Teknis — Contoh per Kategori

Klik "＋ Tambah Baris" untuk setiap baris di bawah. Pilih yang relevan saja.

**Kompresor AC Split & Cassette / Kulkas / Mobil / Industri:**

| Nama | Isi |
|------|-----|
| Tipe | JT125BAY1L |
| Kapasitas | 1 PK (9000 BTU/h) |
| Jenis | Rotary / Scroll / Piston |
| Refrigeran | R32 |
| Voltase | 220V / 50Hz |
| Kondisi | Baru / Test OK (bekas) |

## 7. Harga & Stok: Strategi

### 7.1 — Cara Menulis Harga

- Tulis **angka polos**: `1850000` → tampil otomatis sebagai **Rp 1.850.000**.
- **Jangan** tulis `1.850.000` / `1,850,000` / `Rp1.85jt` — kolom ini hanya menerima angka.

### 7.2 — Kapan Harga Dikosongkan ("Hubungi Kami")?

| Situasi | Saran |
|---------|-------|
| Harga fluktuatif (freon, besi, gas) | Kosongkan → tampil *"Hubungi Kami"* → pelanggan chat WA |
| Harga berbeda untuk grosir/eceran | Kosongkan, jelaskan di deskripsi |
| Barang pre-order / import | Kosongkan |
| Barang umum berstok | Isi harga — harga jelas = closing lebih cepat |

### 7.3 — Kelola Stok Jujur

- Update stok tiap kali barang keluar-masuk (edit produk → ubah angka "Stok" → Simpan).
- Stok `0` → kartu otomatis berlabel **"Stok Habis"** (barang tetap terlihat, pelanggan tahu barangnya ada, tinggal nunggu restock).
- Barang sudah tidak akan pernah dijual lagi? Jangan dihapus — cukup matikan switch **"Tampilkan di Katalog"** (lihat Bagian 8).

### 7.4 — Panduan Memilih Satuan

| Satuan | Gunakan Untuk |
|--------|---------------|
| `pcs` | Kompresor, motor, kapasitor, termostat, fitting satuan |
| `set` | Paket lengkap (manifold + selang + meteran, hard start kit) |
| `box` | Isi kardus (kapasitor per box isi 50, nipple per box) |
| `pack` | Isi bungkusan (baut & mur, kabel ties) |
| `kg` | Freon/gas per kaleng, oli |
| `meter` | Pipa tembaga, kabel, selang, ducting |
| `liter` | Oli kompresor, coil cleaner cair |

## 8. Mengelola Barang yang Sudah Ada

Semua dari menu **"Produk"**:

### 8.1 — Mencari & Menyaring

- **Kotak pencarian**: ketik nama/merek (hasil muncul otomatis saat Anda berhenti mengetik).
- **Dropdown kategori**: saring per kategori.
- **Dropdown status**: saring semua / aktif / nonaktif.
- Tabel memuat **10 barang per halaman**, gunakan tombol halaman di bawah tabel.

### 8.2 — Mengedit Barang

1. Cari barang di tabel → klik ikon **⋮ (tiga titik)** di ujung baris.
2. Pilih **"Edit"** (ikon pensil) → form terbuka **sudah terisi data lama**.
3. Ubah yang perlu (harga naik, stok masuk, tambah foto, dsb).
4. Klik **"Simpan Perubahan"** → notifikasi *"Produk berhasil diperbarui!"*.

> 💡 Update stok harian tidak perlu buka seluruh form? Tetap lewat Edit — hanya 10 detik: Edit → ganti angka stok → Simpan.

### 8.3 — Toggle Cepat Tanpa Buka Form

Di baris tabel tersedia 2 sakelar langsung:

| Sakelar | Kegunaan |
|---------|----------|
| **Tampilkan di Katalog** | Sembunyikan/tayangkan barang **tanpa menghapusnya**. Cocok untuk: barang habis musiman, draft, barang yang sedang tidak ready. |
| **Bintang (Unggulan)** | Masuk/keluarkan barang dari etalase "Produk Unggulan" di beranda. |

### 8.4 — Menghapus Barang

1. Klik ikon **⋮** → **"Hapus"** (ikon tempat sampah).
2. Kotak konfirmasi muncul: *"Apakah Anda yakin...?"* — klik **"Hapus"** untuk melanjutkan.
3. Barang hilang **permanen** dari database.

> ⚠️ **Sembunyikan ≠ Hapus.** Untuk barang yang mungkin dijual lagi, cukup matikan "Tampilkan di Katalog". Hapus hanya untuk salah input / duplikat.

## 9. Upload Banyak Barang Sekaligus (Batch)

Mau memasukkan 50 barang sekaligus? Jangan asal masuk — pakai alur kerja berikut agar selesai 3× lebih cepat.

### 9.1 — Persiapan (sekali saja, ± 1 jam)

1. **Foto semua barang dulu**, tanpa buka form sama sekali.
2. Simpan ke folder dengan penamaan rapi:
   ```
   📁 Foto-Produk/
   ├─ 001-kompresor-daikin-1pk/   (foto1.jpg, foto2.jpg, ...)
   ├─ 002-kapasitor-35uf/
   ├─ 003-freon-r32/
   └─ ...
   ```
3. **Kompres semua foto sekaligus** di `tinypng.com` (bisa 20 foto sekaligus per batch) → simpan hasilnya, buat folder `Foto-Produk-Kecil/`.
4. **Catat data semua barang di spreadsheet** (Excel/Google Sheets/Word) dengan kolom:
   `No | Nama | Merek | SKU | Kategori | Harga | Stok | Satuan | Deskripsi Singkat | Spesifikasi`
5. Tulis deskripsi secara massal dengan template [Bagian 5](#5-menulis-deskripsi-yang-menjual) — copy-paste lalu ganti kata.

### 9.2 — Eksekusi (± 3 menit per barang)

1. Buka form "Tambah" → jendela form **jangan ditutup** dulu; buka spreadsheet di jendela/layar kedua.
2. Kerjakan **satu kategori dulu sampai habis** (otot "pilih kategori" sudah terlanjur benar → tidak salah kategori).
3. Salin-tempel dari spreadsheet → unggah foto dari folder nomor yang sama → Simpan → centang barang selesai di spreadsheet → lanjut.
4. Istirahat tiap 10 barang. 👀

### 9.3 — Ratusan Barang? Serahkan ke Developer

Untuk import **massal** (100+ barang), data dari spreadsheet bisa diimpor langsung ke database oleh developer lewat script seed (contoh di proyek ini: `scripts/seed-1000.ts` yang memuat 1000 produk sekaligus). Siapkan spreadsheet rapi + folder foto, lalu serahkan.

## 10. Checklist Sebelum Klik "Simpan Produk"

Cetak bagian ini & tempel di dekat komputer:

```
□ Nama produk lengkap: jenis + merek + kapasitas/tipe + (kode part)
□ Kategori sudah benar
□ Harga angka polos tanpa titik (atau sengaja dikosongkan)
□ Stok sesuai kondisi gudang
□ Deskripsi singkat ≤ 160 karakter, menggoda
□ Deskripsi lengkap 3–4 paragraf (fungsi, kompatibilitas, keunggulan, garansi)
□ Spesifikasi teknis minimal 5 baris
□ Foto 3–6 buah, semua < 3MB, format benar (bukan HEIC)
□ Foto pertama adalah foto paling menarik (akan jadi "Utama")
□ Barang terlaris? Switch "Produk Unggulan" ON
```

## 11. Troubleshooting — Masalah Umum & Solusi

| 🔴 Masalah | Penyebab | Solusi |
|-----------|----------|--------|
| Toast: *"'IMG_1234.HEIC' melebihi 3MB"* | Foto terlalu besar (kamera modern 4–8MB) | Kompres di `tinypng.com` → unggah ulang (Bagian 4.3) |
| Toast: *"Format harus JPG, PNG, WEBP, atau GIF"* | Foto iPhone format **HEIC**, atau file PDF/dokumen | Konversi HEIC → JPG (Bagian 4.4); pastikan file benar-benar gambar |
| Toast: *"… bukan file gambar"* | File yang dipilih bukan gambar | Pilih file `.jpg/.png/.webp/.gif` |
| Tombol **"Simpan Produk"** abu-abu tidak bisa diklik | Foto masih dalam proses unggah (lihat spinner "Mengunggah N foto…") | Tunggu sampai spinner selesai → tombol otomatis aktif |
| Toast: *"Nama produk wajib diisi."* | Kolom nama kosong | Isi nama produk lalu simpan lagi |
| Produk tidak muncul di katalog publik | Switch **"Tampilkan di Katalog"** sedang OFF | Buka Edit (atau toggle di tabel) → nyalakan switch |
| Produk tidak muncul di "Produk Unggulan" beranda | Switch **"Produk Unggulan"** OFF | Nyalakan switch bintang di tabel produk |
| Foto/ubah-an tidak terlihat setelah disimpan | Cache browser masih memuat versi lama | Tekan **Ctrl+F5** (Windows) / tutup-buka tab di HP |
| Sesi ter-logout sendiri saat sedang isi form | Sesi login kedaluwarsa demi keamanan | Login ulang. *(Kebiasaan aman: siapkan data di spreadsheet dulu, baru buka form)* |

> Jalan buntu semua? Screenshot masalah + kirim ke developer/WhatsApp teknis Anda.

## 12. FAQ — Pertanyaan yang Sering Ditanyakan

<details>
<summary><strong>Q1: Berapa banyak foto boleh diupload per barang?</strong></summary>

Tidak ada batas sistem — tapi sarankan **3–6 foto**. Terlalu banyak membuat halaman detail lambat dibuka. Foto yang **pertama diunggah otomatis menjadi foto utama**.
</details>

<details>
<summary><strong>Q2: Bagaimana mengganti foto utama?</strong></summary>

Hapus foto utama sekarang (hover → ❌) → foto kedua otomatis naik jadi utama. Atau hapus semua foto lalu unggah ulang dengan urutan yang diinginkan (unggahan pertama = utama).
</details>

<details>
<summary><strong>Q3: Bisa menjual tanpa menampilkan harga?</strong></summary>

Bisa. **Kosongkan kolom Harga** — kartu produk akan menampilkan tombol *"Hubungi Kami"* yang mengarah ke WhatsApp toko.
</details>

<details>
<summary><strong>Q4: Bisa memindahkan barang ke kategori lain?</strong></summary>

Bisa. Edit barang → ganti dropdown "Kategori" → Simpan Perubahan.
</details>

<details>
<summary><strong>Q5: Ada batas jumlah barang?</strong></summary>

Tidak ada. Website ini saat ini sudah mengelola **1000 produk** dengan lancar.
</details>

<details>
<summary><strong>Q6: Kalau barang terjual, stok otomatis berkurang?</strong></summary>

Tidak. Website ini berfungsi sebagai **katalog + pemesanan via WhatsApp** (tidak ada checkout online), jadi stok diupdate **manual**: Edit produk → ubah angka "Stok" → Simpan.
</details>

<details>
<summary><strong>Q7: Bisa upload barang langsung dari HP?</strong></summary>

Bisa — dashboard admin sepenuhnya responsif. Yang perlu diperhatikan di HP: tunggu spinner foto selesai sebelum menekan Simpan, dan tekan tombol Simpan lebar di bagian bawah kolom kanan.
</details>

<details>
<summary><strong>Q8: Foto lama hilang saat saya menggantinya?</strong></summary>

Menghapus foto dari form hanya melepas foto itu dari barang. File di server tetap tersimpan (aman, tidak mengganggu). Yang terhapus permanen hanya data barang ketika Anda menghapus barangnya.
</details>
