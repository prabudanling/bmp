    59→## ✨ Tentang Proyek
    60→
    61→**Berkat Mandiri Pendingin** adalah aplikasi web fullstack untuk bisnis jual-beli
    62→**kompresor AC** dan **sparepart AC** (kapasitor, motor fan, termostat, freon,
    63→fitting, dan lainnya). Dirancang agar pemilik toko **tanpa keahlian coding** bisa:
    64→
    65→- 🛍️ Menampilkan katalog produk yang **rapi, cepat, dan responsif** ke pelanggan
    66→- 📤 **Upload barang sendiri** (nama, foto, harga, stok, deskripsi lengkap, spesifikasi teknis)
    67→- 📨 Menerima **pesan pelanggan** langsung ke dashboard, balas 1-klik via WhatsApp/Email
    68→- ⚙️ Mengatur identitas toko (nama, nomor WA, alamat, jam buka) **tanpa menyentuh kode**
    69→
    70→> 💡 **Kenapa aplikasi ini spesial?**
    71→> Semua data tersimpan di **SQLite** — satu file saja. Tidak perlu install MySQL,
    72→> tidak perlu konfigurasi server database rumit. Upload ke hosting, langsung jalan.

   266→## ⚡ Instalasi 5 Langkah
   267→
   268→> 🎯 **Total waktu: ±3 menit.** Tidak perlu MySQL, tidak perlu Docker.
   269→
   270→```bash
   271→# 1️⃣ Masuk folder proyek
   272→cd berkat-mandiri-pendingin
   273→
   274→# 2️⃣ Install semua dependensi
   275→npm install                 # atau: bun install
   276→
   277→# 3️⃣ Buat struktur database SQLite
   278→npm run db:push
   279→
   280→# 4️⃣ Isi data awal (admin + 6 kategori + 14 produk contoh)
   281→bun scripts/seed.ts         # atau: npx tsx scripts/seed.ts
   282→
   283→# 5️⃣ Jalankan website 🚀
   284→npm run dev
   285→```
   286→
   287→Buka **http://localhost:3000** → login sebagai `admin` / `admin123` → selesai! 🎉
   288→
   289→<details>
   290→<summary>🔧 <b>Butuh variabel lingkungan?</b> (klik untuk buka)</summary>

   293→

   300→JWT_SECRET="ubah-ini-dengan-string-acak-yang-panjang-dan-unik"

   325→## 🗄️ Skema Database
   326→
   327→Database SQLite berisi **5 tabel** (dikelola oleh Prisma):
   328→
   329→### 👤 `Admin` — Akun pemilik toko
   330→| Kolom | Tipe | Keterangan |
   331→|-------|------|-----------|
   332→| `id` | String (cuid) | ID unik |
   333→| `username` | String **unique** | Nama untuk login |
   334→| `password` | String | Hash **bcrypt** (tidak pernah plain-text!) |
   335→| `name` | String | Nama tampil di dashboard |
   336→
   337→### 🗂️ `Category` — Kategori produk
   338→| Kolom | Tipe | Keterangan |
   339→|-------|------|-----------|
   340→| `name` | String **unique** | Misal: "Kompresor AC" |
   341→| `slug` | String **unique** | `kompresor-ac` (untuk URL) |
   342→| `icon` | String | Nama ikon Lucide (default: `package`) |
   343→
   344→### 📦 `Product` — Produk toko (tabel utama)
   345→| Kolom | Tipe | Keterangan |
   346→|-------|------|-----------|
   347→| `name` / `slug` | String | Nama produk & slug unik URL |
   348→| `sku` | String? | Kode stok barang (opsional) |
   349→| `brand` | String? | Merek: Daikin, Panasonic, dll |
   350→| `categoryId` | String? | Relasi ke Category (*SetNull* saat kategori dihapus) |
   351→| `price` | Int? | Dalam **Rupiah**; kosong = *"Hubungi Kami"* |
   352→| `unit` / `stock` | String / Int | Satuan (`pcs`, `unit`) & jumlah stok |
   353→| `shortDesc` / `description` | String | Deskripsi singkat & **deskripsi lengkap** |
   354→| `specs` | String (JSON) | Array spesifikasi: `[{"k":"Merek","v":"Daikin"}]` |
   355→| `images` | String (JSON) | Array URL foto (multi-foto) |
   356→| `isFeatured` / `isActive` | Boolean | Tampilkan di beranda / sembunyikan dari katalog |
   357→| `views` | Int | Penghitung kunjungan detail produk |
   358→
   359→### 📨 `Message` — Pesan dari form kontak
   360→| Kolom | Tipe | Keterangan |
   361→|-------|------|-----------|
   362→| `name` / `phone` / `email` | String | Identitas pengirim (email opsional) |
   363→| `message` | String | Isi pesan |
   364→| `isRead` | Boolean | Status dibaca admin (untuk badge notifikasi) |
   365→
   366→### ⚙️ `Setting` — Pengaturan toko (key-value)
   367→| Kolom | Tipe | Keterangan |
   368→|-------|------|-----------|
   369→| `key` / `value` | String | Contoh: `storeName`, `whatsapp`, `heroTitle`, `logoUrl`, `partnerLogos` (JSON), `faviconUrl` |
   370→
   371→### 📄 `Page` — Halaman konten CMS
   372→| Kolom | Tipe | Keterangan |
   373→|-------|------|-----------|
   374→| `title` / `slug` | String | Judul + alamat (`/p/slug`, unik) |
   375→| `content` | String | HTML dari editor WYSIWYG |
   376→| `excerpt` | String | Ringkasan singkat (opsional) |
   377→| `isPublished` | Boolean | `false` = draf, belum tampil di publik |
   378→| `showInMenu` | Boolean | Masuk menu "Informasi" & footer |
   379→| `sortOrder` / `views` | Int | Urutan menu / counter pembaca |
   380→
   381→> 🌱 **Data awal dari seed:** 1 admin, 6 kategori (Kompresor AC, Motor & Fan,
   382→> Kapasitor, Termostat & Sensor, Freon & Gas, Fitting & Aksesoris),
   383→> 14 produk contoh lengkap dengan spesifikasi & deskripsi, 2 pesan contoh.
   384→> Seed **idempotent** — aman dijalankan berulang, tidak akan menduplikasi data.

   388→## 🔌 Dokumentasi API
   389→
   390→Semua endpoint berawalan `/api`. Respon berformat JSON.
   391→
   392→### 🔐 Autentikasi
   393→
   394→| Metode | Endpoint | Auth | Fungsi |
   395→|--------|----------|:----:|--------|
   396→| `POST` | `/api/auth/login` | — | Login → set cookie JWT `httpOnly` |
   397→| `POST` | `/api/auth/logout` | — | Hapus cookie sesi |
   398→| `GET` | `/api/auth/me` | 🔒 | Data admin yang sedang login |
   399→| `PUT` | `/api/auth/change-password` | 🔒 | Ganti password admin |
   400→
   401→**Contoh login:**
   402→
   403→```bash
   404→curl -X POST http://localhost:3000/api/auth/login \
   405→  -H "Content-Type: application/json" \
   406→  -d '{"username":"admin","password":"admin123"}' \
   407→  -c cookie.txt
   408→# → {"ok":true,"admin":{"username":"admin","name":"Administrator"}}
   409→```
   410→
   411→### 📦 Produk
   412→
   413→| Metode | Endpoint | Auth | Fungsi |
   414→|--------|----------|:----:|--------|
   415→| `GET` | `/api/products` | — | Daftar produk + **filter**: `q` (cari), `category`, `status`, `sort` (`newest`/`popular`/`price-asc`/`price-desc`), `featured`, `page`, `limit` |
   416→| `GET` | `/api/products/:id` | — | Detail produk (via `id` **atau** `slug`) + menambah `views` |
   417→| `POST` | `/api/products` | 🔒 | Buat produk baru |
   418→| `PUT` | `/api/products/:id` | 🔒 | Update produk |
   419→| `DELETE` | `/api/products/:id` | 🔒 | Hapus produk |
   420→
   421→**Contoh ambil katalog + filter:**
   422→
   423→```bash
   424→curl "http://localhost:3000/api/products?q=kompresor&sort=price-asc&page=1&limit=12"
   425→# → {"items":[...],"total":4,"page":1,"totalPages":1}
   426→```

   432→| `GET` | `/api/categories` | — | Semua kategori (beserta jumlah produk) |
   433→| `POST` | `/api/categories` | 🔒 | Buat kategori |

   438→| `PUT` | `/api/messages/:id` | 🔒 | Tandai sudah dibaca |
   439→| `DELETE` | `/api/messages/:id` | 🔒 | Hapus pesan |

   441→| `PUT` | `/api/settings` | 🔒 | Simpan pengaturan (batch key-value) |

   444→| `GET` | `/api/pages` | — | Daftar halaman CMS terbit (`?menu=1` khusus menu, `?all=1` 🔒 termasuk draf) |
   445→| `POST` | `/api/pages` | 🔒 | Buat halaman (slug otomatis dari judul) |
   446→| `GET/PUT/DELETE` | `/api/pages/:id` | 🔒 | Detail / ubah / hapus halaman |
   447→| `GET` | `/api/pages/slug/:slug` | — | Halaman per slug (counter views naik otomatis) |
   448→| `GET` | `/api/media` | 🔒 | Daftar semua file di folder uploads (nama, ukuran, tanggal) |
   449→| `DELETE` | `/api/media?url=` | 🔒 | Hapus file media (proteksi path traversal) |
   450→| `GET` | `/api` | — | Cek status API (health check) |

   452→> 🔒 = butuh login admin (cookie JWT dikirim otomatis oleh browser setelah login)

   475→## 🌐 Cara Deploy
   476→
   477→### Ringkasan Opsi
   478→
   479→| Opsi | Cocok Untuk | Admin Dashboard | Kesulitan | Panduan |
   480→|------|-------------|:---------------:|:---------:|---------|
   481→| 🟢 **PHP Shared Hosting** ⭐ | cPanel hosting biasa (juraganwebsite, dll) — **TANPA Node.js!** | ✅ Penuh | ⭐ | [PANDUAN-DEPLOY-SHARED-HOSTING.md](./PANDUAN-DEPLOY-SHARED-HOSTING.md) |
   482→| 🟦 **cPanel + Node.js App** | Shared hosting berfitur Node.js (Hostinger, Niagahoster, dll) | ✅ Penuh | ⭐⭐ | [TUTORIAL.md §4](./TUTORIAL.md#4-panduan-deploy-ke-shared-hosting-cpanel) |
   483→| 🖥️ **VPS + PM2** | VPS sendiri (DigitalOcean, Vultr, dll) | ✅ Penuh | ⭐⭐⭐ | [TUTORIAL.md §5](./TUTORIAL.md#5-alternatif-deploy-ke-vps) |
   484→
   485→### ⚡ Inti Deploy PHP Shared Hosting (TL;DR) — REKOMENDASI
   486→
   487→```bash
   488→# Di komputer: bangun paket lengkap (statis + PHP API bridge)
   489→bun run build:deploy
   490→# → build/berkat-mandiri-website.zip
   491→```
   492→
   493→1. 📤 cPanel → File Manager → `public_html` → upload ZIP → **Extract**
   494→2. ✅ Selesai! Website langsung tampil — admin `/#/admin` berfungsi penuh
   495→3. 🔐 Segera ganti password admin (Pengaturan → Akun)
   496→4. 🚨 **Website tidak muncul?** Buka `domainanda.com/cek.php` — diagnosis
   497→   otomatis berbahasa Indonesia + solusinya (6 penyebab paling umum dibahas di
   498→   [PANDUAN-DEPLOY-SHARED-HOSTING.md §Website Tidak Muncul](./PANDUAN-DEPLOY-SHARED-HOSTING.md))
   499→
   500→> 💡 **Inovasi PHP API Bridge:** shared hosting biasa (PHP-only) tidak bisa
   501→> menjalankan Node.js — maka dibuat `php-api/`, sebuah jembatan PHP yang
   502→> meniru **100% REST API Next.js** (produk, kategori, settings, upload,
   503→> media, halaman CMS, pesan, stats, auth) dengan penyimpanan file JSON.
   504→> Frontend statis hasil `next build` tetap identik; dashboard admin tetap
   505→> bisa menambah/mengubah produk, upload gambar, dan mengelola CMS langsung
   506→> dari website yang online. Terverifikasi **70/70 pengujian otomatis**.
   507→> Panduan lengkap: [PANDUAN-DEPLOY-SHARED-HOSTING.md](./PANDUAN-DEPLOY-SHARED-HOSTING.md)
   508→>
   509→> 🛟 **Mode Darurat anti-website-kosong:** paket berisi `api-cache/` — bila
   510→> PHP di hosting bermasalah, halaman toko tetap tampil (baca-saja: beranda,
   511→> katalog 1000 produk, detail, CMS) sampai PHP diperbaiki. Semua referensi
   512→> aset relatif sehingga paket juga jalan bila dipasang di subfolder.
   513→>
   514→> 💾 **Backup rutin 2 hal ini di hosting:** folder `uploads/` + folder `api/data/`.
   515→
   516→### ⚡ Inti Deploy cPanel Node.js (TL;DR)
   517→
   518→```bash
   519→# Di komputer: build produksi
   520→npm run build
   521→```
   522→
   523→1. 📤 Upload seluruh folder proyek ke cPanel (File Manager / ZIP)
   524→2. 🟦 cPanel → **Setup Node.js App** → arahkan ke proyek, startup file: `.next/standalone/server.js`
   525→3. 📦 Install dependensi → 🗄️ jalankan `db:push` + seed → ▶️ Restart aplikasi
   526→4. ✅ Selesai!
   527→
   528→> ⚠️ **Penting:** Opsi Node.js menuntut hosting yang mendukung **Node.js App**
   529→> (bukan PHP-only). Untuk hosting PHP-only biasa, gunakan opsi 🟢 di atas.
   530→>
   531→> 💾 **Backup rutin 2 hal ini:** folder `public/uploads/` + file `db/custom.db`.

   535→## 🔐 Keamanan
   536→
   537→- ✅ Password di-hash **bcrypt** (10 rounds) — tidak pernah tersimpan polos
   538→- ✅ Sesi memakai **JWT** dalam cookie `httpOnly` (tahan serangan XSS)
   539→- ✅ Semua endpoint admin **terlindungi middleware** autentikasi
   540→- ✅ Upload file **divalidasi** (tipe & ukuran maks 3MB)
   541→- ✅ Form kontak dilengkapi **honeypot** anti-bot spam
   542→- ✅ Prisma ORM = terlindungi dari **SQL Injection** secara bawaan
   543→
   544→**Checklist sebelum produksi:**
   545→
   546→- [ ] Ganti password admin default (`admin123`)
   547→- [ ] Ganti `JWT_SECRET` dengan string acak unik
   548→- [ ] Aktifkan HTTPS di hosting (SSL/TLS gratis via cPanel — Let's Encrypt)
   549→- [ ] Backup rutin `public/uploads/` + `db/custom.db`

   553→## 🧯 Troubleshooting
   554→
   555→| ❌ Masalah | 💡 Solusi |
   556→|-----------|----------|
   557→| `P1003: database tidak ada` | Jalankan `npm run db:push`, lalu seed ulang |
   558→| Login ditolak padahal password benar | Pastikan sudah seed (`bun scripts/seed.ts`) & cookie browser tidak diblokir |
   559→| Foto tidak muncul | Cek file ada di `public/uploads/`; pastikan folder ikut ter-upload saat deploy |
   560→| Upload foto gagal "terlalu besar" | Maks **3MB** per file — kompres dulu fotonya |
   561→| Port 3000 dipakai aplikasi lain | `npm run dev -- -p 3001` lalu buka `:3001` |
   562→| Hapus kategori ditolak | Kategori masih berisi produk — pindahkan/hapus produknya dulu (ini fitur pengaman!) |
   563→| Website blank putih setelah deploy | Jalankan `npm run build` ulang; pastikan startup file benar (`.next/standalone/server.js`) |
   564→| Perubahan pengaturan tidak muncul | Klik **Simpan** di Pengaturan, lalu refresh halaman (Ctrl+F5) |

   568→## ❓ FAQ
   569→
   570→<details>
   571→<summary><b>Apakah bisa jalan di shared hosting PHP biasa (cPanel tanpa Node.js)?</b></summary>
   572→
   573→Tidak. Aplikasi ini dibangun di **Next.js (Node.js)** — bukan PHP. Anda butuh hosting
   574→dengan fitur **Setup Node.js App** (tersedia di Hostinger, Niagahoster, dsb pada paket
   575→tertentu) atau VPS. Panduan lengkap di [TUTORIAL.md](./TUTORIAL.md).
   576→</details>
   577→
   578→<details>
   579→<summary><b>Apakah harus install MySQL?</b></summary>
   580→
   581→**Tidak perlu!** Database memakai **SQLite** — cukup satu file (`db/custom.db`).
   582→Tidak ada instalasi, tidak ada konfigurasi server database. Backup = copy file-nya saja.
   583→</details>
   584→
   585→<details>
   586→<summary><b>Lupa password admin, bagaimana?</b></summary>
   587→
   588→Jalankan ulang seed admin: hapus row Admin di database (bisa via script Prisma Studio
   589→`npx prisma studio`), lalu `bun scripts/seed.ts` — login kembali dengan
   590→`admin/admin123` dan segera ganti password.
   591→</details>
   592→
   593→<details>
   594→<summary><b>Bisa menambah kategori baru? (misal: "Blower")</b></summary>
   595→
   596→Bisa, dari dashboard: **Kategori → + Kategori Baru**. Isi nama, slug otomatis,
   597→pilih ikon. Kategori baru langsung muncul di katalog & form produk.
   598→</details>
   599→
   600→<details>
   601→<summary><b>Bagaimana cara membuat produk "harga hubungi kami"?</b></summary>
   602→
   603→Kosongkan kolom harga saat membuat produk — katalog otomatis menampilkan
   604→**"Hubungi Kami"** dan tombol WhatsApp tetap berfungsi.
   605→</details>
   606→
   607→<details>
   608→<summary><b>Apakah data produk contoh bisa dihapus?</b></summary>
   609→
   610→Bisa. Hapus satu per satu dari dashboard (📦 Produk → 🗑️), atau mulai dari database
   611→kosong: `npm run db:reset` lalu seed ulang **hanya admin & kategori** (edit seed bila perlu).
   612→</details>
